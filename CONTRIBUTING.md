# Contributing to TEMOA-Italy

TEMOA-Italy is developed by the [MAHTEP Group](http://www.mahtep.polito.it/) and hosted in the [MAHTEP Organization](https://github.com/MAHTEP) on GitHub. Contributions are welcome, in particular new test cases, benchmarks against established tools, updated techno-economic data, and new functionalities.

To simply *use* the model, fork this repository and work on your own fork — no contribution back is required.

## Contributing changes

1. Fork the repository and clone your fork.
2. Create a branch for your work.
3. Make your changes, and document the source of any techno-economic data you add.
4. Test that the model still builds and solves.
5. Open a pull request, filling in the [pull request template](.github/PULL_REQUEST_TEMPLATE/PULL_REQUEST_TEMPLATE.md) that matches your contribution.

Please keep pull requests focused on a single topic — it makes review much faster.

## Opening an issue

Open an issue from the [Issues](https://github.com/MAHTEP/TEMOA-Italy/issues) section, choosing the *bug report*, *feature request*, or *custom* template. Blank issues are not accepted.
